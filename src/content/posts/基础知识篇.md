## 一、拆包组包：让数据提取更丝滑

### 1\. 元组拆包：一键提取多个值

刚学 Python 时，从元组取数据我还傻傻地用索引，比如`r = rgb[0]`。后来发现直接拆包更香：

```python
rgb = (12, 45, 32)
r, g, b = rgb  # 一行搞定三个变量赋值，和`r=rgb[0]`说拜拜～
print(r, g, b)  # 输出：12 45 32
```

不过要注意哦，变量数量必须和容器长度完全一致，不然会报错。比如你写`x, y = (1,2,3)`，Python 会直接甩给你一个`ValueError`，这点一定要记牢。

### 2\. 交换值：一行代码实现变量互换

以前交换两个变量的值，我会用临时变量`temp`过渡，直到发现 Python 的神奇操作：

```python
a, b = 1, 2
a, b = b, a  # 直接交换，背后其实是先把b,a装成元组，再拆包给a,b
print(f"a={a}, b={b}")  # 输出：a=2, b=1
```

这行代码其实藏了个小魔法：右边的`b,a`是装包成元组`(b,a)`，左边的`a,b`则是拆包操作，相当于`(a,b) = (b,a)`，是不是很巧妙？

### 3\. 灵活取部分数据：按需提取不浪费

如果只想拿元组里的部分数据，拆包也能搞定。比如取前两个值，剩下的存到列表：

```python
a = (100, 80, 60, 40, 20)
x, y, *rest = a  # x=100, y=80, rest=[60,40,20]
print(f"前两个值：{x}, {y}，剩余：{rest}")
```

不管是取头尾还是中间部分，都可以用`*`来灵活组合，Python 在这方面真的很自由～

### 4\. 拆包在函数中的应用

调用函数时，如果参数刚好在元组或字典里，直接拆包就能传参：

*   **元组拆包传参**（用`*`）：
    ```python
    def get_sum(x, y, z):
        return x + y + z
    nums = (1, 2, 3)
    print(get_sum(*nums))  # 相当于传入1,2,3，输出6
    ```
    
*   **字典拆包传参**（用`**`）：
    ```python
    def user_info(name, age, addr):
        print(f"姓名：{name}，年龄：{age}，地址：{addr}")
    info = {"name": "张三", "age": 21, "addr": "成都"}
    user_info(**info)  # 直接展开字典为关键字参数
    ```

这里的`*`和`**`在函数调用时就像 “解包器”，把容器里的数据变成函数需要的参数形式。

## 二、函数参数：搞懂这几类就够用了

### 1\. 形参与实参：定义 vs 调用的区别


*   **形参**：定义函数时写的参数，比如`def fun(a, b):`里的`a`和`b`，相当于提前占个位置。
*   **实参**：调用函数时传的具体值，比如`fun(1, 2)`里的`1`和`2`，是真正传给函数的数据。

### 2\. 位置参数：严格按顺序来

这是最基础的参数类型，调用时必须按定义顺序传参，多一个少一个都不行：

```python
def add(a, b):
    return a + b
add(2, 3)  # 正确，返回5
# add(2)  # 报错，少传参数
# add(2, 3, 4)  # 报错，多传参数
```


就像排队买票，必须按顺序来，一个萝卜一个坑。

### 3\. 关键字参数：可以打乱顺序的 “懒人参数”

调用时直接指定参数名，顺序就不重要了，适合参数多的时候避免搞错位置：
```python
def greet(name, age):
    print(f"你好，{name}，今年{age}岁啦！")
greet(age=21, name="张三")  # 和greet("张三", 21)效果一样
```

  

写代码时如果记不清参数顺序，用关键字参数准没错。

### 4\. 默认参数：给参数一个 “备胎值”

定义函数时可以给参数设默认值，调用时如果没传这个参数，就用默认值：
```python
def say_hello(name, msg="你好"):
    print(f"{msg}，{name}！")
say_hello("李四")  # 没传msg，用默认值“你好”，输出：你好，李四！
say_hello("王五", "Hi")  # 传了msg，用传入的值，输出：Hi，王五！
```

  

比如写一个发送邮件的函数，默认收件人可以设为自己，每次调用不用重复写，省事～。

### 5\. 不定长参数：处理不确定数量的输入


*   **`*args`**：接收任意多个未命名参数，存成元组。
    ```python
    def print_args(*args):
        print("接收到的参数：", args)
    print_args(1, 2, 3)  # 输出：(1, 2, 3)
    ```
    
*   **`**kwargs`**：接收任意多个关键字参数，存成字典。
    ```python
    def print_kwargs(**kwargs):
        print("接收到的关键字参数：", kwargs)
    print_kwargs(name="张三", age=21)  # 输出：{'name': '张三', 'age': 21}
    ```  

这两个参数在写工具函数时特别有用，比如日志记录函数，不管传多少参数都能接住。

## 三、面向对象：从 “过程” 到 “对象” 的思维转变

### 1\. 对象是什么？像一个会 “变身” 的字典

刚开始学面向对象时觉得抽象，后来发现对象就像一个 “智能字典”：

  

*   字典用`key:value`存数据，对象用 “属性” 存数据，但需要先 “实例化” 才能用（比如`zhangsan = Student()`）。
*   对象还能有 “方法”（函数），比如`zhangsan.play()`，而字典没有这种行为能力。

### 2\. 类属性 vs 实例属性：共享 vs 专属

*   **类属性**：定义在类里，所有实例共享，比如班级名称。
    ```python
    class Student:
        school = "加州大学"  # 类属性，所有学生都属于这个学校
        def __init__(self, name, age):
            self.name = name  # 实例属性，每个学生名字不同
            self.age = age
    zhangsan = Student("张三", 21)
    print(zhangsan.school)  # 输出：加州大学（共享类属性）
    ```
    
*   **实例属性**：在`__init__`方法里用`self`定义，每个实例独立，比如每个学生的姓名和年龄。

### 3\. 魔术方法：让对象更 “听话”

Python 里有很多以`__`开头和结尾的魔术方法，能赋予对象特殊能力：
*   `__str__`：定义对象打印时的显示内容，比如`print(zhangsan)`会返回你定义的字符串。
    ```python
    class Student:
        def __str__(self):
            return f"学生：{self.name}，年龄{self.age}"
    print(zhangsan)  # 直接打印对象，输出：学生：张三，年龄21
    ```
*   `__call__`：让对象可以像函数一样被调用，比如`zhangsan()`会执行你定义的逻辑。
    ```python
    class Student:
        def __call__(self):
            print(f"{self.name}正在调用对象！")
    zhangsan()  # 输出：张三正在调用对象！
    ```
这些魔术方法就像给对象加了 “快捷键”，用起来超方便。

## 四、模块与包：代码模块化的 “收纳盒”

### 1\. 什么是模块？把代码分门别类存起来

如果把一个 Python 文件（`.py`）看作一个 “工具盒”，里面装着函数、类等工具，这就是模块。比如把常用的数据库操作写成`db_utils.py`，下次直接导入就能用，不用重复写代码。

### 2\. 导入模块的三种方式

*   **完整导入**（`import 模块名`）：
    ```python
    import math
    print(math.pi)  # 用模块名.属性调用，避免命名冲突
    ```
    
*   **按需导入**（`from 模块 import 内容`）：
    ```python
    from math import pi, sqrt
    print(pi)  # 直接用，不用加模块名
    ```
    
*   **改名导入**（`import 模块 as 别名`）：
    ```python
    import numpy as np  # 给长名字模块取别名，比如numpy常用np
    ```
